وصل شدن به حساب لیارا
این نسخه‌ی نمایشیه: سه برنامه‌ی ضبط‌شده از لیارای واقعی (متغیر جاافتاده، باگ کد، نشت حافظه)، بدون حساب و بدون هزینه. هر متنی رو به‌جای کلید بنویس و «وصل شو» رو بزن. مشکل رو بگو، راه‌حل پیشنهادی رو خودت تأیید کن و نتیجه‌ی قبل/بعد رو ببین؛ تغییر فقط شبیه‌سازی می‌شه و «بعد» از ضبط واقعی همون برنامه میاد.
داور یا مهمان؟ کادر کلید رو خالی بذار و «وصل شو» رو بزن: سه برنامه‌ی ضبط‌شده از لیارای واقعی (متغیر جاافتاده، باگ کد، نشت حافظه) باز می‌شه، بدون حساب و بدون هزینه. مشکل رو بگو، راه‌حل رو خودت تأیید کن و قبل/بعد رو ببین (تغییر فقط شبیه‌سازی می‌شه). برای حساب واقعی خودت، کلید API لیارا رو بذار.
  1. در console.liara.ir به بخش «کلیدهای API» برو.
  2. یک کلید با مدت اعتبار کوتاه بساز (مثلاً تا آخر هفته).
  3. کلید رو این‌جا بذار. فقط در حافظه‌ی این سرور می‌مونه و هیچ‌جا ذخیره نمی‌شه.
